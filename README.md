# CodeAlpha Basic Chatbot

A simple rule-based chatbot made in Python for the CodeAlpha internship (Task 4).

## How it works
- The bot asks for your name and uses it in replies.
- It answers set phrases like "hello", "how are you" and "bye".
- Greetings are picked randomly, so replies change.
- If it doesn't understand, it asks the user to type "help".
- The chat ends when the user types "bye".

## How to run
python chatbot.py

## Concepts used
if-elif, functions, loops, input/output, random
